Kratos is an iOS fitness app built in Swift that helps users log workouts, track progress, and train more consistently. The long-term goal is to combine clean workout tracking with AI-driven workout recommendations and planning.

## Features
- Workout logging (sets, reps, weight)
- Workout history and progression tracking
- Simple mobile-first UI designed for fast in-gym use

## Tech Stack
- Swift
- Firebase
- OpenAI API
- Xcode (iOS)

## Roadmap
- AI-generated workout plans based on user goals, equipment, and history
- Personalized progression recommendations
- Social features (sharing workouts, accountability)
